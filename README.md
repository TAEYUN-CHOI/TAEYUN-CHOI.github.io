# TAEYUN CHOI Portfolio

C++ 기반 게임 클라이언트 / 게임엔진 프로그래머를 목표로 하는 최태윤의 개인 포트폴리오 사이트입니다.

## 포트폴리오 방향

이 사이트는 채용자가 첫 화면에서 다음 메시지를 바로 이해하도록 구성했습니다.

> C++와 DirectX 12 기반 자체 게임엔진을 메인 포트폴리오로 만들고, UE5 소스 분석과 기존 게임 프로젝트를 통해 엔진 구조·렌더링·물리 시뮬레이션·게임 시스템 구현 역량을 보여준다.

## 주요 구성

- **TaeEngine v0.1**: C++20 / DirectX 12 기반 자체 게임엔진 메인 포트폴리오
- **SDL2 Artillery Game**: C++ 물리 시뮬레이션 기반 2D 포격 게임
- **RiftBeat**: AI 리듬게임 캡스톤 프로젝트
- **UE5 Source Study Notes**: UE5 구조 분석과 자체 엔진 재설계 노트
- **Study Track**: 그래픽스, 물리, C++ 알고리즘, 엔진 아키텍처 학습 흐름
