C++ 기반 게임 클라이언트·엔진 프로그래머를 목표로, 자체 게임엔진을 직접 설계하고 구현합니다.

단순히 상용 엔진 기능을 사용하는 데서 멈추지 않고, Application Loop, Entity/Component, Asset Handle, Render Queue, D3D12 리소스 관리처럼 게임이 실제로 실행되기 위해 필요한 내부 구조를 코드와 문서로 남깁니다.

UE5 소스 분석은 코드를 복사하기 위한 목적이 아니라, 대형 엔진이 Actor/Component, Asset, RHI/RDG, Editor 문제를 어떻게 해결하는지 관찰하고 내 엔진에 맞는 작은 버전으로 재설계하기 위한 기준으로 활용합니다.
